# LC-TC-for-DMR-with-CSLEM
Low-complexity Tracking Control for Differential-drive Mobile Robots with Current Sensorless Electric Motors

How to run:
1. Modify parameter "TrackType, InitSatesType, DisturbanceType" in "ParameterConfig.m" to select different simulation.
2. Run the simulation program "carSim.mdl" in Matlab (R2020b or higher) simulink (Solver: ode23tb).
